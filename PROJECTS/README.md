# Projects

Learning ke liye banaye mini projects. Har project ka apna folder.

## Naya Project Shuru Karna

1. `PROJECTS/` ke andar naya folder banao — `project-name/` (lowercase-with-dashes)
2. `_templates\project-template.txt` ko copy karo us folder me `README.txt` ke naam se
3. Template fill karo (problem, features, stack, steps)

## Structure

```
PROJECTS/
└── <project-name>/
    ├── README.txt    # project-template.txt se
    └── ...           # source files
```
