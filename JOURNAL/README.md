# Journal

Roz ka TIL (Today I Learned) + har Sunday weekly review.

## Structure

```
JOURNAL/
└── <YYYY>/
    ├── <MM-month>.txt        # Roz ka TIL — ek line per day
    └── week-N-review.txt     # Har Sunday weekly review
```

## TIL — Ek Line Likhna

```powershell
.\_scripts\til.ps1 "Docker multi-stage build se image chhoti hoti hai"
```

> Script automatically `JOURNAL\<year>\<MM-month>.txt` me line jodti hai.

## Weekly Review

1. `_templates\weekly-review-template.txt` copy karo
2. `JOURNAL\<YYYY>\week-N-review.txt` ke naam se save karo
3. Fill karo: kya seekha, kya chhoot gaya, agle hafte focus
