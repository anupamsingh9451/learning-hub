# Cheatsheets

Ek page wale quick-reference: "command bhool gaya" wale 2 minute.
Detail chahiye toh `NOTES/` me usi naam ka group folder dekho.

## Folder Structure

```
CHEATSHEETS/
├── php/
│   ├── php.txt
│   ├── laravel.txt
│   └── codeigniter.txt
├── javascript/
│   ├── react.txt
│   └── node.txt
├── html/
│   ├── bootstrap.txt
│   └── tailwind.txt
├── python/
│   └── python.txt
├── devops/
│   ├── docker.txt
│   ├── powershell.txt
│   └── wsl.txt
└── git/
    └── git.txt
```

## Format

- `.txt`, git.txt jaisa: `TITLE`, `=====`, `Time:` line, numbered `------` sections.
- Har line: label (Hinglish) + command, commands ek hi column me.
- Command hamesha ek line me, taaki seedha copy-paste ho.
- End me `EK LINE YAAD RAKHO`.
