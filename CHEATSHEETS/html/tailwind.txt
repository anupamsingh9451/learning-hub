TAILWIND CSS CHEATSHEET
=======================
Time: 2 min – jab bhi class bhool jao
Version: Tailwind v4


------------------------------------------------------------
1. SETUP (VITE + TAILWIND)
------------------------------------------------------------
    Install                      npm install tailwindcss @tailwindcss/vite
    vite.config.js me            import tailwindcss from '@tailwindcss/vite'  +  plugins: [tailwindcss()]
    CSS file me                  @import "tailwindcss";
    Bina build quick test        <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>


------------------------------------------------------------
2. SPACING AUR SIZE
------------------------------------------------------------
    1 unit = 0.25rem = 4px. Matlab p-4 = 16px.

    Padding                      p-4   px-4   py-2   pt-1
    Margin                       m-4   mx-auto   mt-8   -mt-2
    Width / Height               w-full   w-1/2   h-screen   max-w-md
    Gap (flex/grid me)           gap-4   gap-x-2
    Bachchon ke beech space      space-y-4
    Apni value                   w-[350px]   mt-[13px]


------------------------------------------------------------
