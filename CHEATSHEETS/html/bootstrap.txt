BOOTSTRAP CHEATSHEET
====================
Time: 2 min – jab bhi class bhool jao
Version: Bootstrap 5.3


------------------------------------------------------------
1. SETUP
------------------------------------------------------------
    CSS (head me)                https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css
    JS (body ke end me)          https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js
    npm se                       npm install bootstrap


------------------------------------------------------------
2. LAYOUT (12 COLUMN GRID)
------------------------------------------------------------
    Container                    container   /   container-fluid
    Do barabar column            row > col-md-6 + col-md-6
    Auto barabar column          row > col + col + col
    Column ke beech gap          g-3   gx-2   gy-4
    Breakpoints                  sm 576   md 768   lg 992   xl 1200


------------------------------------------------------------
3. SPACING (0 SE 5)
------------------------------------------------------------
    Formula: m ya p + side + size. Side: t b s(start) e(end) x y.

    Example                      mt-3   px-2   mb-0   p-4
    Center karo                  mx-auto


------------------------------------------------------------
4. FLEX AUR UTILITIES
------------------------------------------------------------
    Flex                         d-flex align-items-center justify-content-between
    Gap                          gap-2
    Mobile pe chhupao            d-none d-md-block
    Text                         text-center   fw-bold   text-secondary
    Color                        text-primary   bg-light   bg-danger
    Border / round               border   rounded   shadow-sm


------------------------------------------------------------
5. COMPONENTS
------------------------------------------------------------
    Button                       btn btn-primary   btn-outline-secondary
    Chhota button                btn btn-sm
    Form                         form-label   form-control   form-select
    Card                         card > card-body > card-title
    Alert                        alert alert-success
    Table                        table table-striped table-hover
    Modal kholne wala button     data-bs-toggle="modal" data-bs-target="#myModal"
    Dark mode                    <html data-bs-theme="dark">


------------------------------------------------------------
EK LINE YAAD RAKHO
------------------------------------------------------------
    Modal, dropdown ke liye bootstrap.bundle.min.js zaroori hai
    (Popper isi me hai).
