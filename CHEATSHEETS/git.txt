GIT CHEATSHEET
==============
Time: 2 min – jab bhi command bhool jao


------------------------------------------------------------
1. ROZ KE COMMANDS
------------------------------------------------------------
  Status dekho                 git status
  Sab add                      git add -A
  Commit                       git commit -m "msg"
  Push                         git push
  Latest lao                   git pull
  History                      git log --oneline --graph -20
  Remote dekho                 git remote -v


------------------------------------------------------------
2. BRANCH
------------------------------------------------------------
  Naya branch                  git switch -c feature/x
  Branch badlo                 git switch main
  Saare branch                 git branch -a


------------------------------------------------------------
3. GALTI SUDHARNA
------------------------------------------------------------
  Last commit ka msg sudharo   git commit --amend -m "naya msg"
  (sirf push se PEHLE)
  File ka change undo          git restore file.txt
  Add kiya hua hatao           git restore --staged file.txt
  Kaam side me rakho           git stash      /   git stash pop


------------------------------------------------------------
EK LINE YAAD RAKHO
------------------------------------------------------------
  Push ho chuke commit ko amend/rebase mat karo – naya commit banao.
