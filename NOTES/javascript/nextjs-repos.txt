2. LOGIN AUR DATABASE
------------------------------------------------------------
    nextauthjs/next-auth
        Kya hai : Auth.js. Google, GitHub, email login.
        Kab lo  : Next.js app me login.

    better-auth/better-auth
        Kya hai : Naya TypeScript auth library, features zyada.
        Kab lo  : 2FA, organization/teams wala login chahiye.

    prisma/orm
        Kya hai : Prisma ORM. Schema file se database aur types.
        Kab lo  : MySQL/Postgres ke saath type-safe queries.

    drizzle-team/drizzle-orm
        Kya hai : Halka TypeScript ORM, SQL jaisa likhte hain.
        Kab lo  : SQL pe zyada control chahiye.
