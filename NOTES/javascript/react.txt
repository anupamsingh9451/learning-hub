3. REACT KAISE KAAM KARTA HAI
------------------------------------------------------------
    STEP 1 – Tum component likhte ho jo batata hai "UI kaisa dikhe".
    STEP 2 – React use chala ke ek virtual (memory wala) UI banata hai.
    STEP 3 – State/props badle toh component dobara chalta hai (re-render).
    STEP 4 – React naye aur purane UI ko compare karta hai (reconciliation).
    STEP 5 – Sirf jo badla, wahi asli DOM me update hota hai.

    Re-render kab hota hai?
    - Component ki apni state badle.
    - Parent re-render ho (bachche bhi chalte hain).
    - Jis context ko use kar rahe ho, uski value badle.

    Yaad rakho: re-render ka matlab DOM badalna nahi. Component function
    dobara chalta hai, DOM sirf farak pe badalta hai.

5. JSX KE RULES
------------------------------------------------------------
    JSX = JavaScript ke andar HTML jaisa likhna.

        const name = 'Anupam';
        return (
            <div className="card">
                <h1>Hello {name}</h1>
                <img src={user.photo} alt="" />
                <label htmlFor="email">Email</label>
            </div>
        );

    - Ek hi parent element return karo. Extra div nahi chahiye toh <>...</>.
    - class -> className, for -> htmlFor.
    - Har tag band hona chahiye: <img />, <br />.
    - { } ke andar JavaScript expression (if statement nahi, ternary chalega).
    - style object hota hai: style={{ fontSize: 14 }}
    - Events camelCase: onClick, onChange, onSubmit.

6. COMPONENTS AUR PROPS
------------------------------------------------------------
    Component = function jo JSX return kare. Naam Capital letter se.

        function Button({ label, variant = 'primary', onClick }) {
            return (
                <button className={`btn btn-${variant}`} onClick={onClick}>
                    {label}
                </button>
            );
        }

        <Button label="Save" onClick={save} />

    Props:
    - Parent se child ko data. Read-only, child unhe badal nahi sakta.
    - Function bhi prop me jaata hai (child -> parent baat karne ke liye).

    children (beech ka content):
        function Card({ title, children }) {
            return <div className="card"><h2>{title}</h2>{children}</div>;
        }

        <Card title="Profile"><p>Kuch bhi andar</p></Card>

    Condition aur list:
        {isLoggedIn ? <Dashboard /> : <Login />}
        {error && <p className="error">{error}</p>}
        {items.map(item => <Row key={item.id} item={item} />)}

    key:
    - List me har item ki unique aur stable key do (database id).
    - Index ko key mat banao agar list sort/delete hoti hai. Galat item
      update ho jaata hai.

7. STATE – useState
------------------------------------------------------------
        const [count, setCount] = useState(0);

        <button onClick={() => setCount(count + 1)}>{count}</button>

    Pichli value pe depend ho toh function do:
        setCount(c => c + 1);

    Object aur array – hamesha naya banao (immutable):
        setUser({ ...user, name: 'Anupam' });
        setItems([...items, newItem]);                 // add
        setItems(items.filter(i => i.id !== id));       // delete
        setItems(items.map(i => i.id === id ? { ...i, done: true } : i));

    Kyun naya? React purane aur naye object ka reference compare karta hai.
    items.push() se reference same rehta hai, toh UI update nahi hota.

    Batching:
    - Ek event me kai setState hon toh React ek hi baar re-render karta hai.
    - setState ke turant baad value purani hi dikhegi. Nayi value agle
      render me milti hai.

    Derived state mat banao:
        // GALAT: fullName ke liye alag state
        // SAHI: render me hi nikal lo
        const fullName = `${first} ${last}`;

9. useEffect – SIDE EFFECTS
------------------------------------------------------------
    Side effect = render ke bahar ka kaam: API call, timer, event
    listener, document.title badalna.

        useEffect(() => {
            const id = setInterval(tick, 1000);
            return () => clearInterval(id);     // cleanup
        }, []);

    Dependency array:
        useEffect(fn)          har render ke baad
        useEffect(fn, [])      sirf pehli baar (mount)
        useEffect(fn, [id])    jab id badle

    Data fetch (race condition se bachav ke saath):
        useEffect(() => {
            let ignore = false;
            fetch(`/api/users/${id}`)
                .then(r => r.json())
                .then(data => { if (!ignore) setUser(data); });
            return () => { ignore = true; };
        }, [id]);

    Effect ki zaroorat NAHI:
    - Props/state se kuch calculate karna -> render me hi karo.
    - Button click pe kuch karna -> event handler me karo.
    - Real app me data fetch -> TanStack Query lo.

    Development me StrictMode effect ko do baar chalata hai. Yeh bug
    pakadne ke liye hai, production me ek hi baar chalega.

    React 19 me <ThemeContext> seedha provider hai (pehle
    <ThemeContext.Provider> likhte the, woh bhi chalta hai).

12. useReducer – BADI STATE LOGIC
------------------------------------------------------------
        function cartReducer(state, action) {
            switch (action.type) {
                case 'add':    return [...state, action.item];
                case 'remove': return state.filter(i => i.id !== action.id);
                case 'clear':  return [];
                default:       return state;
            }
        }

        const [cart, dispatch] = useReducer(cartReducer, []);
        dispatch({ type: 'add', item });

    Kab lo: ek state ke kai tarah ke updates hon (cart, multi-step form).

13. CUSTOM HOOKS – LOGIC REUSE
------------------------------------------------------------
    Custom hook = "use" se shuru hone wala function jo dusre hooks use kare.

        function useLocalStorage(key, initial) {
            const [value, setValue] = useState(() => {
                const saved = localStorage.getItem(key);
                return saved ? JSON.parse(saved) : initial;
            });

            useEffect(() => {
                localStorage.setItem(key, JSON.stringify(value));
            }, [key, value]);

            return [value, setValue];
        }

        const [theme, setTheme] = useLocalStorage('theme', 'light');

    Hooks ke rules:
    - Sirf component ya custom hook ke top level pe call karo.
    - if, loop, ya nested function ke andar nahi.

14. PERFORMANCE
------------------------------------------------------------
    Pehle naapo, phir sudhaaro. React DevTools ka Profiler use karo.

    memo – props same toh component dobara mat chalao:
        const Row = memo(function Row({ item }) { ... });

    useMemo – bhaari calculation yaad rakho:
        const sorted = useMemo(() => sortBig(list), [list]);

    useCallback – function ka reference same rakho (memo child ke liye):
        const onSelect = useCallback(id => setSelected(id), []);

    React Compiler:
    - Build time pe yeh memo/useMemo/useCallback khud laga deta hai.
    - Naye project me on kar sakte ho. Haath se memo kam likhna padta hai.

    Code splitting (page tabhi load ho jab chahiye):
        const Reports = lazy(() => import('./pages/Reports'));
        <Suspense fallback={<Spinner />}><Reports /></Suspense>

    Badi list (1000+ rows): virtualization (TanStack Virtual), sirf dikhne
    wali rows render hoti hain.

    State ko neeche rakho: jis component ko chahiye, wahi rakhe. Upar
    rakhoge toh poora page re-render.

22. GALTIYAN JO MAINE KI / GOTCHAS
------------------------------------------------------------
    - State ko seedha badla (push, obj.x = 1). UI update nahi hua.
    - useEffect me dependency bhool gaya, purani value use hoti rahi.
    - useEffect me object/array dependency, har render naya, infinite loop.
    - {count && <p/>} me count 0 hua toh screen pe "0" chhap gaya.
      Use: {count > 0 && <p/>}
    - setState ke turant baad console.log me purani value. Normal hai.
    - Component ke andar component define kiya, har render naya bana,
      input ka focus chala gaya. Component hamesha bahar define karo.
    - API key frontend code me daali. Frontend ka sab kuch public hai.

23. INTERVIEW ANGLE
------------------------------------------------------------
    Q: Virtual DOM kya hai?
    A: UI ki memory me copy. React naye aur purane ko compare karke sirf
       farak asli DOM me lagata hai.

    Q: Props aur state me farak?
    A: Props bahar (parent) se aate hain, read-only. State component ki
       apni hoti hai, badal sakti hai.

    Q: key kyun zaroori hai?
    A: React ko list items pehchanne ke liye. Isse sahi item update hota
       hai aur performance achhi rehti hai.

    Q: useEffect cleanup kab chalta hai?
    A: Agla effect chalne se pehle aur component hatne (unmount) pe.

    Q: useMemo aur useCallback me farak?
    A: useMemo value yaad rakhta hai, useCallback function yaad rakhta hai.

    Q: Controlled vs uncontrolled input?
    A: Controlled me value React state me. Uncontrolled me value DOM me,
       ref ya FormData se padhte hain.

    Q: Prop drilling kaise hatate ho?
    A: Context, composition (children pass karo), ya Zustand.

    Q: Re-render kam kaise karoge?
    A: State neeche rakho, memo, useMemo/useCallback, React Compiler,
       list virtualization.
