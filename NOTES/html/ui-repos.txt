UI KE KAAM KE REPOS
===================
Topic: UI libraries, icons, animation, admin templates
Date: 24-10-2026
Time: ~5 min padhne me
Link: https://github.com/<repo naam>  (repo ka naam hi uska link hai)


------------------------------------------------------------
1. COMPONENT LIBRARIES
------------------------------------------------------------
    shadcn-ui/ui
        Kya hai : React components jo copy hoke tumhare project me aate
                  hain (Tailwind + Radix pe bane). Jaisa chaho badlo.
        Kab lo  : React/Next.js me dashboard, form, modal jaldi banana ho.

    radix-ui/primitives
        Kya hai : Bina design ke components (dropdown, dialog, tabs) jo
                  keyboard aur screen reader ke saath sahi chalte hain.
        Kab lo  : Apna design khud banana ho, par behaviour ready chahiye.

    saadeghi/daisyui
        Kya hai : Tailwind ke upar ready classes jaise btn, card, modal.
        Kab lo  : Blade, CodeIgniter view ya plain HTML. React zaroori nahi.

    themesberg/flowbite
        Kya hai : Tailwind components + unka JS (dropdown, modal chalane ke
                  liye).
        Kab lo  : Laravel/PHP project me Tailwind UI bina React ke.

    mui/material-ui
        Kya hai : Google ke Material design wale React components.
        Kab lo  : Bada React app, jahan sab kuch ready chahiye.

    ant-design/ant-design
        Kya hai : Enterprise React UI. Tables aur forms bahut strong.
        Kab lo  : Admin panel jisme bahut saari tables aur filters hon.

    twbs/bootstrap
        Kya hai : Purana bharosemand CSS framework.
        Kab lo  : Purane PHP projects, ya jaldi ek simple page.


------------------------------------------------------------
2. ICONS
------------------------------------------------------------
    lucide-icons/lucide
        Kya hai : Saaf, simple icons. shadcn/ui me yahi default hain.
        Kab lo  : React/Next.js project.

    tabler/tabler-icons
        Kya hai : Hazaron free SVG icons.
        Kab lo  : Kahin bhi, PHP view me bhi SVG copy karke.

    tailwindlabs/heroicons
        Kya hai : Tailwind team ke icons.
        Kab lo  : Tailwind wale project me matching look ke liye.

    realvjy/3dicons (https://3dicons.co)
        Kya hai : 1,440+ free open-source 3D icons (PNG, OBJ, FBX, BLEND).
        Kab lo  : Landing page hero aur bento grid me tactile 3D look ke liye.


------------------------------------------------------------
3. ANIMATION
------------------------------------------------------------
    motiondivision/motion
        Kya hai : React animation library (pehle naam Framer Motion tha).
        Kab lo  : Page transition, hover, smooth show/hide.

    magicuidesign/magicui
        Kya hai : Animated landing page components (shadcn style).
        Kab lo  : Portfolio ya product landing page ko fancy banana ho.

    skiper-ui (https://skiper-ui.com)
        Kya hai : shadcn-compatible uncommon animations (dynamic islands, cursor trails).
        Kab lo  : Next.js/Tailwind me unique award-winning interactions chahiye.

    vengeance-ui (https://vengenceui.com)
        Kya hai : Vibe-coding aur AI agents (Cursor/Claude MCP) ke liye motion UI kit.
        Kab lo  : Prompt se animated blocks aur CLI registry se add karna ho.

    scrolltide (https://scrolltide.co)
        Kya hai : Scroll-driven 3D shaders, sections aur cinematic AI prompt library.
        Kab lo  : Cursor/Claude me prompt daal kar high-impact scroll effects ke liye.


------------------------------------------------------------
4. TABLE, FORM, CHART
------------------------------------------------------------
    TanStack/table
        Kya hai : Table ka logic (sort, filter, pagination), design tumhara.
        Kab lo  : React me badi data table.

    react-hook-form/react-hook-form
        Kya hai : React forms jo fast hain aur validation aasan.
        Kab lo  : Login, signup, koi bhi bada form.

    recharts/recharts
        Kya hai : React ke liye charts.
        Kab lo  : React dashboard me graph.

    chartjs/Chart.js
        Kya hai : Plain JavaScript charts.
        Kab lo  : Blade/PHP page me graph, bina React ke.


------------------------------------------------------------
5. READY ADMIN TEMPLATES
------------------------------------------------------------
    ColorlibHQ/AdminLTE

        Kab lo  : PHP/CodeIgniter client project me admin panel jaldi.

    tabler/tabler

        Kab lo  : AdminLTE se naya aur saaf look chahiye.

    satnaing/shadcn-admin

        Kab lo  : React admin panel ka ready starting point.
