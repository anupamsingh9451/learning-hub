1. EK LINE ME
------------------------------------------------------------
    UI design = screen pe jo dikhta hai aur jisse user baat karta hai
    (button, form, menu, rang, font) usko sundar aur aasan banana.
    UI style = us design ka "look aur feel".

    Misaal: Ek hi kamra. Minimal = safed deewar, kam furniture.
    Maximal = rangeen deewar, bahut saari cheezein. Kamra wahi, feel alag.


------------------------------------------------------------
2. UI DESIGN KYA HOTA HAI (UI vs UX)
------------------------------------------------------------
    UI (User Interface) = DIKHNA
    - Button kaisa dikhe, kaunsa rang, kaunsa font, kitni jagah.

    UX (User Experience) = CHALNA
    - User apna kaam kitni aasani se kar paata hai. Kitne click, kahan
      confuse hota hai, kitna time lagta hai.

    Misaal: Restaurant.
    - UI = menu card ka design, plate, table ki sajawat.
    - UX = order kitni jaldi hua, waiter ko bulana aasan tha ya nahi.

    Sundar UI par kharab UX = user pareshan. Achha UX par kharab UI =
    bharosa kam. Dono chahiye.


------------------------------------------------------------
3. UI KE BUILDING BLOCKS (HAR STYLE INHI SE BANTA HAI)
------------------------------------------------------------
    1) Color      – ek main (primary) rang, 1-2 accent, baaki gray.
                    60-30-10 rule: 60% base, 30% secondary, 10% accent.
    2) Typography – 1-2 font family. Size ka ek scale (12, 14, 16, 20,
                    24, 32, 48). Body text 16px se kam nahi.
    3) Spacing    – 4 ya 8 ke multiple (4, 8, 16, 24, 32). Har jagah
                    same scale, toh design apne aap saaf lagta hai.
    4) Layout     – grid (12 column), alignment, khaali jagah (whitespace).
    5) Components – button, input, card, modal, navbar, table.
    6) Icons aur images – ek hi style ke icons (sab outline ya sab filled).
    7) Motion     – hover, transition, loading. Chhota aur tez (150-300ms).

    Design system = in sab ke rules + ready components ek jagah
    (jaise Google ka Material, IBM ka Carbon). Team me sab same banate hain.


------------------------------------------------------------
4. ACHHE UI KE 8 RULES (STYLE KOI BHI HO)
------------------------------------------------------------
    1) Hierarchy    – sabse zaroori cheez sabse badi/bold. Aankh pehle
                      wahin jaaye.
    2) Contrast     – text aur background ka contrast 4.5:1 se kam nahi.
    3) Consistency  – same kaam ka button har jagah same dikhe.
    4) Alignment    – sab kuch kisi line pe aligned. Tedha-medha nahi.
    5) Proximity    – judi cheezein paas-paas, alag cheezein door.
    6) Feedback     – click hua toh dikhe (loading, success, error).
    7) Simplicity   – har screen pe ek main kaam.
    8) Accessibility– keyboard se chale, label ho, sirf rang se meaning
                      mat do.

7. STYLE KAISE CHUNEIN – 4 SAWAL
------------------------------------------------------------
    1) User kaun hai?
       Bank/hospital/govt -> bharosa, saaf UI (minimal, material, utilitarian).
       Gen-Z / creator -> bold, playful (neubrutalism, maximal, Y2K).
    2) Kaam kya hai?
       Roz ka tool (dashboard) -> padhne me aasan, kam decoration.
       Ek baar dekhne wala (landing page, portfolio) -> wow factor chalega.
    3) Content kitna hai?
       Bahut data -> minimal, flat, enterprise. Kam content -> 3D, maximal.
    4) Accessibility?
       Contrast 4.5:1. Neumorphism, glass, duotone me yeh mushkil hota hai.

8. MINIMALISM
------------------------------------------------------------

    Pehchan : Bahut whitespace, 1-2 rang, saaf font, kam border/shadow,

    Kab lo  : SaaS, portfolio, premium brand, docs, dashboard.
    Kab nahi: Jab brand ko masti/energy dikhani ho.

              Tailwind: py-24 max-w-3xl mx-auto text-gray-900

49. GALTIYAN JO MAINE KI / GOTCHAS

    - Trend dekh ke style chuna, user nahi dekha. Bank app neubrutalism me.
    - Glassmorphism safed background pe. Effect dikha hi nahi.
    - Neumorphism me buttons pehchan me nahi aaye. Contrast check nahi kiya.

    - 3D/animation mobile pe bhaari. Lighthouse score gira.
    - Animation lagaya, prefers-reduced-motion bhool gaya.
    - Style pe dhyan, spacing aur typography pe nahi. Asli farak wahi
      dalte hain.

50. INTERVIEW ANGLE
------------------------------------------------------------
    Q: UI aur UX me farak?
    A: UI = dikhna (rang, font, button). UX = user ka poora experience,
       kaam kitni aasani se hota hai.

    Q: Glassmorphism aur Neumorphism me farak?
    A: Glass me transparent, blur kaanch jaisi layer (backdrop-filter).
       Neumorphism me element background ka hi rang, do shadows se ubhra
       hua lagta hai.

    Q: Neumorphism kam kyun use hota hai?
    A: Contrast kam, button aur normal area ka farak samajh nahi aata.

    Q: Brutalism aur Neubrutalism me farak?
    A: Brutalism kachcha, bina design ka. Neubrutalism rangeen, mote
       borders, hard shadows, jaan-boojh ke stylish.

    Q: Design system kya hai?
    A: Colors, fonts, spacing ke rules + ready components ek jagah, taaki
       poori team ek jaisa UI banaye. Jaise Material, Carbon, Fluent.

    Q: Dark mode me kya dhyan rakhoge?
    A: Pure black/white nahi, contrast check, shadow ki jagah lighter
       surfaces, user ko toggle aur system setting dono.

    Q: Bento grid kya hai?
    A: Alag size ke cards wala grid, ek screen me kai features. CSS grid
       + span se banta hai.
