# Notes

Topic-wise apne notes. Har topic ka apna folder.

## Folder Structure

```
NOTES/
├── php-laravel/
├── react-js/
├── python/
├── ai-llm/
├── database/
├── devops-linux/
├── git/
└── system-design/
```

## Naya Note Kaise Banayein

```powershell
.\_scripts\new-note.ps1 -Topic ai-llm -Title "RAG kya hai"
```

> `NOTES\ai-llm\rag-kya-hai.txt` ban jayega — `_templates\note-template.txt` ke format me.

## File Naming Convention

```
<lowercase-with-dashes>.txt
# e.g.  eloquent-relationships.txt
#        rag-kya-hai.txt
```
