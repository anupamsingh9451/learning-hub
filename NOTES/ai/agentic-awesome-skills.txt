1. EK LINE ME
------------------------------------------------------------
    Yeh GitHub repo 2,743 "skills" ka bada collection hai. Skill = ek
    folder jisme SKILL.md file hoti hai, jo AI agent ko batati hai ki koi
    kaam step by step kaise karna hai. Claude Code, Cursor, Gemini CLI,
    Codex, Antigravity, Kiro, OpenCode sab ke liye chalta hai.

    Misaal: Claude Code ek naya, smart developer hai. Skill ek "recipe
    card" hai: "bug aaye toh pehle reproduce karo, phir root cause, phir
    fix, phir test". Claude card padhta hai aur usi tareeke se kaam karta
    hai. Yeh repo = 2,700 recipe cards ki kitaab.

    Purana naam: antigravity-awesome-skills (pehle Antigravity ke liye
    bana tha, ab sab tools ke liye hai).


------------------------------------------------------------
2. SKILL ASAL ME HOTI KYA HAI
------------------------------------------------------------
    Ek skill ka folder:
        skills/
        └── systematic-debugging/
            └── SKILL.md        (kabhi saath me scripts/, references/)

    SKILL.md ka shuru (frontmatter) kuch aisa hota hai:
        ---
        name: systematic-debugging
        description: Use when encountering any bug, test failure, or
          unexpected behavior, before proposing fixes
        ---
        (neeche steps, rules, examples)

    Kaise chalti hai:
    - Claude ko shuru me sirf har skill ka naam + description dikhta hai.
    - Tumhara kaam description se match kare, tabhi Claude poori file
      kholta hai. Isliye description sabse zaroori line hai.
    - Skill program nahi hai, sirf instructions hain. Khatra tab hai jab
      skill Claude se shell command, file delete, network call karwaye.

    Skill vs MCP vs CLAUDE.md (confuse mat hona):
        CLAUDE.md   is project ke rules, har baar load hote hain
        Skill       ek kaam ka tareeka (gyaan), zaroorat pe load hota hai
        MCP         bahar ka tool (haath): DB, browser, GitHub API

5. SETUP – CLAUDE CODE (WINDOWS)
------------------------------------------------------------
    Teen raaste hain. Pehla ya doosra lo, teesra mat.

    RAASTA 1 – PLUGIN MARKETPLACE (sabse aasan)
        Claude Code ke andar:
            /plugin marketplace add sickn33/agentic-awesome-skills
            /plugin install agentic-awesome-skills
            /reload-plugins
        README ke hisaab se yeh "plugin-safe filtered" version hai, matlab
        poori library nahi, chhaanti hui skills. Hatana ho toh /plugin se
        uninstall.

    RAASTA 2 – SIRF CHUNI HUI SKILLS (mera pasandeeda)
        STEP 1 – Project folder me jao, pehle git commit
            cd D:\projects\eduassist
            git add -A; git commit -m "before skills"

        STEP 2 – Dry run (kuch copy nahi hota, sirf dikhata hai)
            npx agentic-awesome-skills@19.15.0 --release 19.15.0
                --path .claude\skills
                --skills "brainstorming,systematic-debugging,laravel-expert"
                --dry-run
            (yeh sab EK hi line me likhna, yahan padhne ke liye toda hai)

        STEP 3 – Output theek lage toh wahi line bina --dry-run chalao.

        STEP 4 – Claude Code band karke dobara kholo, phir "/" type karke
                 dekho skills dikh rahi hain ya nahi.

        Path ka farak:
            .claude\skills                      sirf is project ke liye
            $env:USERPROFILE\.claude\skills     har project ke liye

        Sirf safe skills chahiye toh --risk "safe,none" bhi laga sakte ho.

    RAASTA 3 – POORI LIBRARY (mat karo)
            npx agentic-awesome-skills --claude
        2,700 skills ek saath. Context bhar jaata hai, Claude confuse hota
        hai. Docs khud bolte hain: 3-5 skills se shuru karo.

    Check (PowerShell):
        Test-Path .claude\skills
        Test-Path "$env:USERPROFILE\.claude\skills"

10. SAFETY – YEH ZAROOR PADHO
------------------------------------------------------------
    - Yeh community repo hai (Anthropic ka nahi). Har skill alag log ne
      likhi hai. 48k stars matlab review nahi.
    - Install se pehle SKILL.md khud padho. Agar woh curl, rm, .env,
      tokens ki baat kare, toh samjho kyun.
    - Version pin karo (@19.15.0). "latest" har baar naya code laata hai.
    - Pehle --dry-run, phir asli install. Pehle git commit.
    - Remote script ko seedha shell me pipe mat karo (curl ... | bash).
    - Antivirus kisi SKILL.md ko flag kare: security wali skills me exploit
      ke naam likhe hote hain, isliye flag aa sakta hai. Phir bhi us skill
      ko hata do aur dekho kya likha hai, chalao mat.
    - Client ke project me pehli baar try mat karo. Test project pe karo.
    - Claude ki permissions bypass wale flags mat lagao, skill kuch bhi
      bole.

14. INTERVIEW ANGLE
------------------------------------------------------------
    Q: Agent skill kya hai, aur MCP se kaise alag hai?
    A: Skill ek SKILL.md file hai jisme kaam karne ka tareeka likha hai.
       Agent ko pehle sirf naam + description dikhta hai, zaroorat pe
       poori file load hoti hai (isse context bachta hai). MCP ek server
       hai jo agent ko naye tools deta hai (DB query, API call). Skill =
       "kaise karna hai", MCP = "kis cheez se karna hai".

    Q: Skill ki description itni important kyun hai?
    A: Agent description padh ke hi tay karta hai skill kholni hai ya
       nahi. Description dheeli ho toh skill kabhi trigger nahi hogi, ya
       galat jagah trigger hogi.
