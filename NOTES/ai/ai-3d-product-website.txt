1. EK LINE ME
------------------------------------------------------------
    AI tools se ek premium product website banana jisme product pe hover
    (ya scroll) karte hi woh khul ke apne parts me bikhar jaata hai
    ("exploded view"), jaise Apple ki AirPods page pe hota hai.

    Misaal: Ek flip-book. Har page pe tasveer thodi badli hui hai. Tezi
    se palto toh lagta hai tasveer chal rahi hai. Yahan bhi video ko
    100 tasveeron (frames) me todte hain, aur mouse/scroll se "page
    palatte" hain.


------------------------------------------------------------
2. TECHNIQUE: FRAME SEQUENCE (VIDEO KYUN NAHI?)
------------------------------------------------------------
    Video ko seedha lagao toh:
    - Scroll ke saath aage-peeche smooth "scrub" nahi hota, atakta hai.
    - Hover chhodne pe ulta chalana (reverse) mushkil.

    Frame sequence (JPG/WebP tasveerein + <canvas>):
    - Har frame pe poora control: aage, peeche, beech me rukna.
    - Mouse/scroll ki position = frame number.
    - Apple apne product pages pe yahi tareeka use karta hai.

    Flow:
        Product image -> AI video (exploded) -> JPG frames -> canvas pe
        frame number badalte raho

5. FRAME SEQUENCE KA CODE (SAMJHNE KE LIYE)
------------------------------------------------------------
    AI yahi type ka code likhega. Samajh loge toh check aur sudhaar
    paoge.

    Hover pe khulna, mouse hatane pe wapas (plain JS + canvas):
        <canvas id="product" width="1600" height="900"></canvas>

        const canvas = document.getElementById('product');
        const ctx = canvas.getContext('2d');
        const TOTAL = 96;
        const frames = [];

        for (let i = 1; i <= TOTAL; i++) {
            const img = new Image();
            img.src = `/assets/aurix/exploded-frames/frame_${String(i).padStart(3, '0')}.jpg`;
            frames.push(img);
        }

        let current = 0;
        let target = 0;

        function draw(i) {
            if (frames[i].complete) ctx.drawImage(frames[i], 0, 0, canvas.width, canvas.height);
        }

        function tick() {
            if (current !== target) {
                current += current < target ? 1 : -1;   // ek-ek frame aage/peeche
                draw(current);
            }
            requestAnimationFrame(tick);
        }

        frames[0].onload = () => draw(0);
        tick();
        canvas.addEventListener('mouseenter', () => { target = TOTAL - 1; });
        canvas.addEventListener('mouseleave', () => { target = 0; });

    Scroll ke saath (GSAP ScrollTrigger):
        gsap.registerPlugin(ScrollTrigger);
        const state = { frame: 0 };

        gsap.to(state, {
            frame: TOTAL - 1,
            snap: 'frame',
            ease: 'none',
            scrollTrigger: { trigger: '#engineering', start: 'top top', end: '+=2000', scrub: true, pin: true },
            onUpdate: () => draw(state.frame),
        });

        scrub: true = scroll jitna, animation utni. pin = section ruka
        rahe jab tak animation poori na ho.

6. PERFORMANCE, MOBILE, ACCESSIBILITY
------------------------------------------------------------
    Bhaar ka hisaab: 96 frames x 150 KB = ~14 MB. Mobile pe bahut zyada.

    [ ] Frames WebP me (JPG se ~30% chhote). Squoosh/ffmpeg se.
    [ ] 60-90 frames, width 1280-1600px kaafi.
    [ ] Mobile pe kam aur chhote frames (alag folder), ya sirf static
        exploded image.
    [ ] Frames tab load karo jab section paas aaye (IntersectionObserver),
        page khulte hi nahi.
    [ ] Pehla frame turant dikhe (placeholder), baaki background me.
    [ ] Mobile pe hover hota hi nahi -> scroll ya tap se chalao.
    [ ] prefers-reduced-motion: animation band, seedha final image.
    [ ] Labels ("40mm Driver") asli text ho, image me nahi (screen reader
        aur SEO ke liye).
    [ ] Lighthouse/PageSpeed se score check karo.

9. GALTIYAN / GOTCHAS
------------------------------------------------------------
    - 300 frames full-HD JPG daal diye, mobile pe page 40 MB ka.
    - Flow ne har frame me product thoda badal diya (shape/color). Image
      ko strong reference do, prompt me "same product" likho.
    - Video me camera ghooma, frames hilte dikhe. Static camera maango.
    - Frames ka order galat (frame_1, frame_10, frame_2). 001, 002 jaisi
      padding do.
    - Sirf hover banaya, mobile pe kuch hua hi nahi.
    - 21st API key code me likh di aur GitHub pe push ho gayi.
    - Kisi asli brand (Sony, Apple) ka naam/logo use kiya – copyright ka
      jhanjhat. Fictional brand rakho.
    - AI ne "done" bola, par frames load hi nahi ho rahe the (galat path).
      Network tab me 404 dekho.
