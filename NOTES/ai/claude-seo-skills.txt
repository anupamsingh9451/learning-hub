2. MODERN SEARCH KA KHEL: SEO VS GEO VS AEO
------------------------------------------------------------
    2026 me sirf Google ke 10 blue links ke liye optimize karna kaafi nahi hai.
    Search 3 hisson me bat chuki hai:

    1. Traditional SEO (Search Engine Optimization):
       - Focus: Google / Bing organic rankings, page speed, backlinks.
       - Metric: Organic impressions, click-through rate (CTR), SERP position.

    2. GEO (Generative Engine Optimization):
       - Focus: ChatGPT Search, Perplexity, Claude, aur Copilot me tumhari site
         as a trusted source cite hona.
       - Tareeka: `llms.txt` file setup, crisp factual definitions, clear entity
         markup, clean markdown layout jo AI crawlers aasani se parse karein.

    3. AEO (Answer Engine Optimization):
       - Focus: Google AI Overviews (SGE) aur voice search me seedha answer box
         (Featured Snippet) me aana.
       - Tareeka: Har heading ke turant baad 40-60 words ka direct, definitive
         answer + bullet point summary + Schema FAQ/HowTo markup.

3. 7 CORE SKILL MODULES (NOTION BLUEPRINT)
------------------------------------------------------------
    Notion doc me Claude ke liye 7 specialized modules define kiye gaye hain:

    Module 1: Technical & Core Web Vitals Audit
        - Robots.txt, XML sitemap validation, canonical tags audit.
        - Broken internal links, 404s, aur 301 redirect chain detection.
        - Mobile responsiveness, semantic HTML tags (<main>, <article>, <nav>).

    Module 2: GEO & AI Search Readiness (`llms.txt`)
        - Site root pe `/llms.txt` aur `/llms-full.txt` generate karna taaki
          LLMs tumhare brand aur products ko accurate facts ke sath cite karein.
        - Entity extraction: brand name, founder, core offerings ko schema
          knowledge graph se link karna.

    Module 3: Semantic Keyword Clustering & Intent Mapping
        - Raw keyword export (Ahrefs/SEMrush ya free tools) ko 3 buckets me todna:
          * Informational: "how to implement redis queue in laravel"
          * Commercial / Comparison: "laravel vs nodejs for high traffic"
          * Transactional: "hire vetted laravel developers"
        - Duplicate keyword cannibalization khatam karna.

    Module 4: High-Rank Content Brief & E-E-A-T Scoring
        - Google E-E-A-T framework:
          * Experience: Asli code snippets aur screenshots (not stock).
          * Expertise: Deep technical gotchas, edge cases.
          * Authoritativeness: Source citations aur official docs links.
          * Trustworthiness: Clear author bio, privacy policy, contact.
        - Outline format: H1 (Target Keyword) -> H2 (Sub-topics) -> H3 (Steps).

    Module 5: Structured Data & Schema Markup (JSON-LD)
        - Har page ke liye copy-paste ready `<script type="application/ld+json">`.
        - Schemas: Article, FAQPage, HowTo, SoftwareApplication, Organization,
          BreadcrumbList.
        - Rich Snippet stars aur FAQs Google SERP pe click rate 20-35% badhate hain.

    Module 6: Internal Linking & Topic Silo Architecture
        - "Pillar Page" (Parent topic, e.g., Laravel Guide) se "Cluster Pages"
          (Child topics, e.g., Laravel Eloquent, Laravel Queues) ka interlinking.
        - Anchor text optimization: Exact match vs partial match balancing.
        - Orphan pages (bina link wale dead pages) ko pakadna aur link karna.

    Module 7: Competitor SERP Gap Analysis
        - Top 3 ranking pages ko analyze karna: "Inhone kya miss kiya?"
        - Missing FAQs, outdated information, ya complex language ko pakad kar
          behtar, aasan aur comprehensive guide taiyyar karna.

6. GALTIYAN JO NAHI KARNI (GOTCHAS)
------------------------------------------------------------
    - AI Se Blindly 100 Articles Mat Likhao:
      Google ka "Helpful Content System" mass AI spam ko de-index kar deta hai.
      10 badhiya, deep, problem-solving guides > 100 thin AI articles.

    - Fake Data / Hallucinated Stats Mat Dalo:
      AI aksar fake stats bol deta hai ("78% developers prefer..."). Hamesha
      asli research paper ya company study ka link verify karo.

    - Schema Validate Karna Mat Bhoolo:
      Code banate hi Google Rich Results Test (search.google.com/test/rich-results)
      me paste karke check karo ki koi syntax error toh nahi.

    - Keywords Stuff Mat Karo:
      Keywords ko baar-baar zabardasti ghusana (keyword stuffing) 2010 ka
      tareeka hai. Semantic entities aur related topics use karo.
