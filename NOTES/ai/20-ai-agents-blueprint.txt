1. EK LINE ME
------------------------------------------------------------
    Business ke roz ke kaam (email, leads, meeting notes, proposals,
    invoices, content) ke liye 20 AI agents ka blueprint. Har agent = ek
    trigger + context + AI brain + action + insaan ki approval.

    Misaal: Naye interns ki team. Har intern ka ek kaam, ek rulebook, aur
    bada kaam bhejne se pehle tumhara sign. Agents wahi interns hain.


------------------------------------------------------------
2. HAR AGENT KE 5 HISSE
------------------------------------------------------------
    Trigger   – kab chalega (time, koi event, ya tumhara message)
    Context   – kya jaanta hai (tumhara data, rules, achhe output ke examples)
    Brain     – AI model (Claude) jo padhta aur sochta hai
    Action    – tools me kya karta hai (label, draft, sheet update)
    Approval  – bahar jaane se pehle insaan check karta hai

    Doc ki sabse kaam ki line: kharab output aksar kamzor context ki wajah
    se aata hai, model ki wajah se nahi. Rules aur examples sudhaaro.


------------------------------------------------------------
3. BANANE KE 4 TAREEKE

    2) Automation tool (n8n / Make / Zapier) + Claude as brain – doosre
       apps ke events, multi-step, zyada volume. (6 agents)
    3) Ready-made AI tool – jo kaam koi tool pehle se achha karta hai
       (Apollo, Opus Clip, Intercom, ManyChat). (5 agents)

    Shuruaat tareeka 1 se. n8n me pehle ek row pe test, phir live.

    limit zaroor.

4. PROMPT KA 6 HISSON WALA FORMULA
------------------------------------------------------------
    Role         – agent kaun hai
    Context      – business, rules, examples (business brain)
    Task         – exact steps
    Rules        – kya KABHI nahi karna
    Output       – exact format aur length
    Uncertainty  – shak ho toh kya kare (jaise [CHECK] likhe, guess na kare)

    Mere saare 14 agents isi formula pe bane hain.

6. TEEN TRUST LEVELS – SEEDHA AUTOPILOT NAHI
------------------------------------------------------------
    Level 1 Shadow    – agent sirf batata hai kya karega. 10 runs lagatar
                        sahi -> agla level.
    Level 2 Approve   – agent sab taiyar karta hai, tum click karke approve.
                        2 hafte tak almost sab bina badlav approve -> agla.
    Level 3 Autopilot – agent khud karta hai, tum daily log dekho. Sirf
                        low-risk kaam.

    Paisa, hiring aur client messages HAMESHA Level 2 pe.
    Mere agents Level 2 pe hain: sirf draft/report, kuch bhejte nahi.

11. TROUBLESHOOTING
------------------------------------------------------------
    Generic / brand se alag output   -> business brain + 2 achhe examples do
    Cheezein bana leta hai           -> "sirf diye gaye data se" + uncertainty rule
    Ek baar chala, phir fail         -> connection expire / column naam badla
    Har baar alag format             -> strict output format (fields, JSON)
    Workflow chala hi nahi           -> trigger timezone, webhook URL, ON hai?
    Kharch zyada                     -> kam frequency, sirf naye items, spend limit
    Same item do baar                -> ID / done flag save karo
    Tool block karta hai             -> official integration ya woh step haath se


------------------------------------------------------------
12. HONEST LIMITS
------------------------------------------------------------
    - Agents galti karte hain: email galat padhna, detail banana, galat
      time. Bahar jaane wali har cheez pe approval.
    - WhatsApp: opt-in + approved templates, per message charge.
      Instagram: sirf unko reply jo pehle message karein. Cold email:
      unsubscribe option + warmed-up domain.
    - CV, contracts, inbox jodne se pehle tool ki data settings dekho
      (India DPDP Act, GDPR).
    - Hiring aur paisa ke faisle insaan karega; agent sirf taiyari.
    - Tools ka kharch judta hai – free tier se shuru, sirf time bachane
      wale agents pe paisa.
