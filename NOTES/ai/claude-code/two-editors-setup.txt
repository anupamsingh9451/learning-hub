Topic: ai

Time: ~15 min setup
Status: setup ho gaya (24-10-2026). Baaki: OpenRouter key daalna.
Setup: VS Code (normal)      = original Claude (mera account / subscription)

------------------------------------------------------------
1. EK LINE ME
------------------------------------------------------------
    VS Code ko alag "--user-data-dir" aur "--extensions-dir" ke saath
    kholo toh woh bilkul alag VS Code ban jaata hai: apni settings, apne
    extensions. Usme Claude Code ko CLAUDE_CONFIG_DIR se alag folder do –
    ek window original Claude, doosri OpenRouter.

    Misaal: Ek ghar, do meter. Ek room ka bill mere naam (subscription),
    doosre room ka prepaid card (OpenRouter credit). Wiring alag.

    Pehle plan Antigravity ka tha, par mere laptop wala Antigravity (v2.11)
    "Agentic Desktop Application" hai – code editor nahi, usme VS Code
    extensions nahi lagte. Isliye do VS Code.


------------------------------------------------------------
2. KYA KAHAN HAI
------------------------------------------------------------
    VS Code (normal) – original Claude
        Settings:   %APPDATA%\Code\User\settings.json
        Extensions: %USERPROFILE%\.vscode\extensions
        Claude:     %USERPROFILE%\.claude  (mera login, CLAUDE.md, agents)

    VS Code (OpenRouter)
        Kholo:      Desktop shortcut "VS Code (OpenRouter)"
        Settings:   %USERPROFILE%\.vscode-openrouter\data\User\settings.json
        Extensions: %USERPROFILE%\.vscode-openrouter\extensions
                    (Claude Code v2.1.310 installed)
        Claude:     %USERPROFILE%\.claude-openrouter
                    (settings.json me OpenRouter env, CLAUDE.md, RTK.md,
                    14 agents ki copy)
        Pehchan:    title bar laal-bhura, title me "[OpenRouter]"

    Shortcut ka command (haath se bhi chala sakte ho):
        "%LOCALAPPDATA%\Programs\Microsoft VS Code\Code.exe" --user-data-dir "%USERPROFILE%\.vscode-openrouter\data" --extensions-dir "%USERPROFILE%\.vscode-openrouter\extensions"

3. KYA BADLA (24-10-2026)
------------------------------------------------------------
    VS Code (normal) settings:
    - Pehle kisi local proxy ke liye set tha: ANTHROPIC_BASE_URL =
      http://127.0.0.1:8082, token "freecc", gateway discovery, auto mode
      server off, advisor tool off, auto-compact 190000,
      disableLoginPrompt = true. Port 8082 pe kuch chal nahi raha tha.
    - Ye proxy wali entries HATAYI, disableLoginPrompt = false kiya.
    - Rakhi: DISABLE_AUTOUPDATER, DISABLE_FEEDBACK_COMMAND,
      DISABLE_ERROR_REPORTING (meri choices).
    - Backup: %APPDATA%\Code\User\settings.backup-2026-10-24.json

    VS Code (OpenRouter) settings (naya):
        "claudeCode.disableLoginPrompt": true,
        "claudeCode.environmentVariables": [
            { "name": "CLAUDE_CONFIG_DIR", "value": "C:\\Users\\Anupam Singh\\.claude-openrouter" }
        ],
        "terminal.integrated.env.windows": {
            "CLAUDE_CONFIG_DIR": "C:\\Users\\Anupam Singh\\.claude-openrouter"

        ANTHROPIC_DEFAULT_OPUS/SONNET/HAIKU_MODEL = anthropic/claude-*-5.5


------------------------------------------------------------
4. BAAKI KAAM – KEY DAALNA
------------------------------------------------------------
    STEP 1 – https://openrouter.ai/keys pe key banao, credit limit lagao.
    STEP 2 – %USERPROFILE%\.claude-openrouter\settings.json me
             "PASTE-OPENROUTER-KEY-HERE" ki jagah key, save.
    STEP 3 – Desktop shortcut "VS Code (OpenRouter)" se kholo.
    STEP 4 – Claude panel me /status -> base URL https://openrouter.ai/api.


------------------------------------------------------------
5. CHECK KARNA
------------------------------------------------------------
    [ ] VS Code (normal) -> /status -> mera account, koi custom base URL nahi
        (pehli baar login maange toh apne account se login)
    [ ] VS Code (OpenRouter) -> /status -> OpenRouter base URL
    [ ] OpenRouter window me ek sawaal -> https://openrouter.ai/activity
        pe dikhe; normal window ka sawaal wahan NA dikhe
    [ ] OpenRouter window me usage bars nahi dikhenge (third-party pe normal)


------------------------------------------------------------
6. WAPAS KAISE (UNDO)
------------------------------------------------------------
    - Normal VS Code purani halat me: backup file ko settings.json pe copy
      karo (proxy wali settings wapas aa jaayengi).
    - OpenRouter VS Code hatana: Desktop shortcut delete, phir
      %USERPROFILE%\.vscode-openrouter aur %USERPROFILE%\.claude-openrouter
      folder delete. OpenRouter pe key revoke.


------------------------------------------------------------
7. GALTIYAN / GOTCHAS
------------------------------------------------------------
    - CLAUDE_CONFIG_DIR me "~" likha – extension ignore karta hai. Poora path.
    - Purana proxy (127.0.0.1:8082) settings me reh gaya – "connection
      refused". (normal VS Code se hata diya hai)
    - Normal VS Code ke extensions OpenRouter wali me nahi hain – jo chahiye
      woh OpenRouter window me alag install karo.
    - History alag: ek window ki Claude chats doosri me nahi dikhengi.
    - Agents ya CLAUDE.md badla toh dono jagah (.claude aur
      .claude-openrouter) update karo.
    - Key plain text me hai – .claude-openrouter folder share/backup me
      dhyan.
    - Lambi agent sessions OpenRouter window me = credit jaldi khatam.
      Bhaari roz ka kaam normal window (subscription) me.
