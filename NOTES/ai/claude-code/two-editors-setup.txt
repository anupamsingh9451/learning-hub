    OpenRouter wale ko alag folder do.

    doosre room ka prepaid card (OpenRouter credit). Wiring alag, takraav
    nahi.

2. KAISE KAAM KARTA HAI
------------------------------------------------------------
    Antigravity --> Claude Code ext --> config: C:\Users\Anupam Singh\.claude
                                        (default, mera login yahin hai)

    VS Code     --> Claude Code ext --> config: C:\Users\Anupam Singh\.claude-openrouter

    - Extension me CLAUDE_CONFIG_DIR ka path POORA (absolute) dena, "~"
      nahi chalta.
    - Source: code.claude.com/docs/en/vs-code (Extension settings) aur
      installed extension ki package.json (format: [{name, value}]).

------------------------------------------------------------
4. STEP A – ANTIGRAVITY = ORIGINAL CLAUDE
------------------------------------------------------------
    STEP 1 – Antigravity kholo -> Extensions -> "Claude Code" search ->
             Install (Anthropic ka; forks me Open VSX se aata hai).
    STEP 2 – Antigravity ki User Settings (JSON) me koi
             "claudeCode.environmentVariables" ya ANTHROPIC_* NAHI hona
             chahiye. Default rehne do.
    STEP 3 – Claude panel kholo. Login maange toh apne account se login.
             (Login %USERPROFILE%\.claude me pehle se hai, shayad seedha
             chal jaaye.)
    STEP 4 – /status -> account wala login dikhna chahiye, koi custom base
             URL nahi.


------------------------------------------------------------
5. STEP B – VS CODE = OPENROUTER
------------------------------------------------------------
    STEP 1 – OpenRouter key banao (https://openrouter.ai/keys), key pe credit
             limit lagao (jaise $10). Detail: openrouter-claude.txt

    STEP 2 – Alag config folder banao aur zaroori files copy karo
             (PowerShell, ek-ek line):
        New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude-openrouter"
        Copy-Item "$env:USERPROFILE\.claude\CLAUDE.md","$env:USERPROFILE\.claude\RTK.md","$env:USERPROFILE\.claude\settings.json" "$env:USERPROFILE\.claude-openrouter\"
        (Plugins/skills copy nahi hote – zaroorat ho toh naye folder me
        dobara install karo.)

    STEP 3 – "%USERPROFILE%\.claude-openrouter\settings.json" me "env" block
             jodo. Key SIRF yahin, ek jagah:
        {
            "env": {
                "ANTHROPIC_BASE_URL": "https://openrouter.ai/api",
                "ANTHROPIC_AUTH_TOKEN": "<openrouter-key>",
                "ANTHROPIC_API_KEY": "",
                "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
                "ANTHROPIC_DEFAULT_OPUS_MODEL": "anthropic/claude-opus-5.5",
                "ANTHROPIC_DEFAULT_SONNET_MODEL": "anthropic/claude-sonnet-5.5",
                "ANTHROPIC_DEFAULT_HAIKU_MODEL": "anthropic/claude-haiku-5.5"
            },
            ... (copy hui baaki settings – hooks, permissions – waise hi)
        }

    STEP 4 – VS Code: Ctrl+Shift+P -> "Preferences: Open User Settings
             (JSON)". Purane proxy wale entries HATAO (BASE_URL 8082,
             freecc) aur ye rakho:
        "claudeCode.disableLoginPrompt": true,
        "claudeCode.environmentVariables": [
            { "name": "CLAUDE_CONFIG_DIR", "value": "C:\\Users\\Anupam Singh\\.claude-openrouter" }
        ],
        "terminal.integrated.env.windows": {
            "CLAUDE_CONFIG_DIR": "C:\\Users\\Anupam Singh\\.claude-openrouter"
        }
        Purane me se ye chahe toh rakh sakte ho: CLAUDE_CODE_AUTO_COMPACT_WINDOW,
        DISABLE_AUTOUPDATER, DISABLE_ERROR_REPORTING.

    STEP 5 – VS Code restart. Claude panel me /status:
             base URL = https://openrouter.ai/api, token = ANTHROPIC_AUTH_TOKEN.
             VS Code terminal me "claude" bhi OpenRouter se chalega.

------------------------------------------------------------
8. GALTIYAN / GOTCHAS
------------------------------------------------------------
    - CLAUDE_CONFIG_DIR me "~\.claude-openrouter" likha – extension ne
      ignore kiya, default folder use hua. Poora path do.
    - Purana proxy (127.0.0.1:8082) settings me reh gaya – requests band
      proxy pe gayi, "connection refused".
    - ANTHROPIC_API_KEY kahin set reh gaya – Claude Code ne seedha Anthropic
      ko try kiya. OpenRouter wale me khaali rakho.
    - Naye folder me RTK hook, CLAUDE.md nahi the – copy karna bhool gaya.
    - History alag hai: VS Code (OpenRouter) ki purani chats Antigravity me
      nahi dikhengi, aur ulta bhi.
    - Key plain text me settings.json me hai – folder kisi ko mat bhejo,
      backup/screenshot me dhyan.
    - OpenRouter wale editor me lambi agent sessions = credit jaldi khatam.
      Roz ka bhaari kaam Antigravity (subscription) me karo.
