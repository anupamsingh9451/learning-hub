4. KAHAN AUR KAISE USE KAREIN
------------------------------------------------------------

    TAREEKA A – "VS Code (OpenRouter)" window me Claude Code:
    --------------------------------------------------------
    File: %USERPROFILE%\.claude-openrouter\settings.json
    Settings me env block update karo:

    {
      "env": {
        "ANTHROPIC_BASE_URL": "https://openrouter.ai/api",
        "ANTHROPIC_AUTH_TOKEN": "<YOUR-OPENROUTER-KEY>",
        "ANTHROPIC_API_KEY": "",
        "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
        "ANTHROPIC_DEFAULT_SONNET_MODEL": "qwen/qwen-2.5-coder-32b-instruct:free",
        "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek/deepseek-chat:free"
      }
    }

    Dhyan: Claude Code extension Anthropic ke custom prompts ke liye bani
    hai. Free models code likh denge, par complex agentic tool-use me kabhi-kabhi
    schema mismatch de sakte hain.


    TAREEKA B – Cline Extension (SABSE RELIABLE AUR SMOOTH):
    --------------------------------------------------------
    Aapke laptop par Cline pehle se installed hai. Cline OpenRouter native
    support karta hai aur tool-use 100% stable chalta hai:

    1. VS Code me Cline icon kholo -> Settings (gear icon).
    2. API Provider: "OpenRouter" select karo.
    3. OpenRouter API Key: apni "<YOUR-OPENROUTER-KEY>" paste karo.
    4. Model ID: "qwen/qwen-2.5-coder-32b-instruct:free" chuno.
    5. Save karo. Ab Cline free me full coding, file edits aur terminal chalaega.


    TAREEKA C – Terminal / PowerShell se test call:
    ----------------------------------------------
    PowerShell me check karne ke liye:

    $key = "<YOUR-OPENROUTER-KEY>"
    $body = @{
      model = "qwen/qwen-2.5-coder-32b-instruct:free"
      messages = @(@{ role = "user"; content = "Hello! Ek line me introduction do." })
    } | ConvertTo-Json

    Invoke-RestMethod -Uri "https://openrouter.ai/api/v1/chat/completions" `
      -Method Post `
      -Headers @{ "Authorization" = "Bearer $key"; "Content-Type" = "application/json" } `
      -Body $body | Select-Object -ExpandProperty choices | Select-Object -ExpandProperty message

5. GALTIYAN / GOTCHAS
------------------------------------------------------------
    - Claude model ka naam daal diya aur socha free chalega:
      "anthropic/claude-sonnet-5.5" likhoge toh OpenRouter "Insufficient credits"
      error de dega. Model ke aage ":free" hona zaroori hai.
    - 50 requests ki limit:
      Lambi multi-file loop ya endless terminal commands me 50 requests jaldi
      khatam ho sakti hain. Chhote specific sawaalon aur targeted edits ke liye use karo.
    - Provider rate limits / busy error:
      Free models par worldwide traffic hota hai. Agar "Provider returned error (429/503)"
      aaye toh doosra free model try karo (jaise Qwen busy ho toh DeepSeek Chat chuno).
    - Key plain-text me leak mat hone dena:
      Bhale hi free account ho, key git me commit nahi honi chahiye.
