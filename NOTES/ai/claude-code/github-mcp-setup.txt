------------------------------------------------------------
1. EK LINE ME
------------------------------------------------------------
    Abhi Claude mere laptop ki files dekh sakta hai, par GitHub website
    pe kya hai (repos, issues, PR) woh nahi dekh sakta. Is guide ke baad
    main "claude" GitHub se baat kar payega, jaise main khud browser me
    login karke karta hoon.

    Misaal: Claude ek naya employee hai. Use office (GitHub) ka ek
    access card (token) dena hai, jisme likha ho woh kaunse kamre
    (permissions) me ja sakta hai.


------------------------------------------------------------
2. PEHLE YEH SHABD SAMJHO
------------------------------------------------------------
    Terminal     : kaala/neela window jisme commands type karte hain.
                   Is guide me "PowerShell" use karenge.
    Command      : terminal me type ki gayi ek line. Copy karo, terminal
                   me right-click se paste karo, Enter dabao.
    Token (PAT)  : GitHub ka ek lamba password jaisa code, jaise
                   github_pat_11ABC... Yeh sirf Claude ke liye banta hai,
                   aur isme limit hoti hai ki woh kya kar sakta hai.
                   PAT = Personal Access Token.
    Environment  : Windows ki ek chhoti "tijori" jahan naam ke saath
    variable       value rakhte hain (GITHUB_PAT = token). Programs naam
                   se value utha lete hain, token kahin file me likhna
                   nahi padta.
    MCP server   : ek "adapter" jo Claude ko kisi bahar ki service
                   (yahan GitHub) se jodta hai.
    gh           : GitHub ka official command tool. Claude PR banane
                   jaise kaam isi se karta hai.

4. STEP 1 – GITHUB PE TOKEN BANAO (~5 MIN)
------------------------------------------------------------
    1) Browser me yeh link kholo (GitHub me login hona chahiye):
           https://github.com/settings/personal-access-tokens/new

       Kya dikhega: "New fine-grained personal access token" page.

    2) Form bharo:
       - Token name        : claude-code-main
       - Description       : Main Claude Code ke liye
       - Resource owner    : apna naam (anupamsingh9451) rehne do
       - Expiration        : 90 days
       - Repository access : "All repositories" chuno
                             (seekhne ke liye aasan. Baad me
                             "Only select repositories" kar sakte ho.)

    3) Neeche "Permissions" me "Repository permissions" kholo. Sirf yeh
       chaar badlo, baaki jaise hain waise rehne do:
       - Contents       ->  Read and write
       - Issues         ->  Read and write
       - Pull requests  ->  Read and write
       - Actions        ->  Read-only
       ("Metadata: Read-only" apne aap aa jaata hai, theek hai.)

    4) Sabse neeche hare button "Generate token" pe click.
       Ek popup aaye to dobara "Generate token" dabao.

    5) Ab token dikhega (github_pat_... se shuru). Copy button dabao.

       ZAROORI: yeh token sirf ABHI ek baar dikhega. Page band karne se
       pehle use step 2 me use kar lo, aur ek copy apne secure
       credentials folder me ek text file me rakh lo.

       Token kabhi mat daalna: learning-hub repo me, kisi note me,
       WhatsApp/chat me, ya Claude ke chat box me.


------------------------------------------------------------
5. STEP 2 – TOKEN KO WINDOWS ME SAVE KARO (~3 MIN)
------------------------------------------------------------
    1) Start menu me "PowerShell" likho, "Windows PowerShell" kholo.
       (VS Code ka terminal NAHI, alag window.)

    2) Yeh command copy karo. Pehle Notepad me paste karke
       github_pat_YAHAN_APNA_TOKEN ki jagah apna asli token daalo
       (dono taraf ke ' quotes mat hatana):

           [Environment]::SetEnvironmentVariable('GITHUB_PAT', 'github_pat_YAHAN_APNA_TOKEN', 'User')

       Ab Notepad se poori line copy karke PowerShell me paste karo,
       Enter dabao.

       Kya dikhega: kuch nahi. Koi error nahi aaya = save ho gaya.

    3) Ab yeh sab BAND karo: saare PowerShell windows aur VS Code.
       (Naya variable sirf naye khule windows me dikhta hai.)

    4) Naya PowerShell kholo aur check karo:

           if ($env:GITHUB_PAT) { 'set hai' } else { 'nahi mila' }

       "set hai" aaya    -> aage badho.
       "nahi mila" aaya  -> step 2 dobara karo, phir saare windows band
                            karke kholo.


------------------------------------------------------------
6. STEP 3 – MAIN CLAUDE ME GITHUB JODO (~2 MIN)
------------------------------------------------------------
    Usi naye PowerShell window me:

    1) Pehle check karo terminal "saaf" hai:

           $env:CLAUDE_CONFIG_DIR

       Kuch nahi aaya (khaali line)  -> sahi hai, aage badho.
       Koi path aaya                 -> pehle yeh chalao:
                                        Remove-Item Env:CLAUDE_CONFIG_DIR

    2) Ab yeh command copy-paste karo (bilkul aise hi, isme kuch mat
       badlo, token yahan nahi daalna):

           claude mcp add --transport http --scope user github https://api.githubcopilot.com/mcp/ --header 'Authorization: Bearer ${GITHUB_PAT}'

       Kya dikhega: "Added HTTP MCP server github ..." jaisa message.

    Yeh kya karta hai: main Claude ko bolta hai "GitHub naam ka ek
    adapter jodo, aur login ke liye GITHUB_PAT naam ki tijori se token
    utha lena". Token khud config me nahi likha jaata.


------------------------------------------------------------
7. STEP 4 – CHECK KARO KI JUD GAYA (~3 MIN)
------------------------------------------------------------
    1) Usi PowerShell me:

           claude mcp list

       Sahi: github ... ✔ Connected
       Galat: github ... ✘ Failed to connect  -> section 10 dekho

    2) Ab Claude chalao:

           claude

       Claude ke andar likho:  /mcp
       List me "github" ke aage ✔ hona chahiye. Esc dabake bahar aao.

    3) Claude se poocho (normal chat ki tarah):

           mere GitHub ke saare repos ki list do

       Claude GitHub tool use karne ki permission maangega. Padho,
       "Yes" dabao. Repos ki list aa gayi = setup poora.

    4) Bonus check: "claude-personal" ya "claude-work" chalao, /mcp
       likho. Wahan github NAHI hona chahiye. Yahi chahiye tha.


------------------------------------------------------------
8. STEP 5 – GH TOOL LAGAO (PR KE LIYE, ~5 MIN)
------------------------------------------------------------
    1) PowerShell me:

           winget install --id GitHub.cli

       "Do you agree..." pooche to Y likho, Enter.
       Kya dikhega: "Successfully installed".

    2) PowerShell band karke naya kholo. Phir:

           gh auth login

       Yeh 4 sawal poochega. Arrow keys se chuno, Enter dabao:
       - Where do you use GitHub?          -> GitHub.com
       - Preferred protocol?               -> HTTPS
       - Authenticate Git with credentials -> Y
       - How would you like to login?      -> Login with a web browser

       Ek 8 akshar ka code dikhega (jaise ABCD-1234). Enter dabao,
       browser khulega, code daalo, "Authorize" dabao.

    3) Check:

           gh auth status

       "Logged in to github.com account anupamsingh9451" = ho gaya.

    Note: gh ka login teeno Claude ke liye common hai (poore laptop ka).
    Yeh theek hai.

10. AGAR DIKKAT AAYE
------------------------------------------------------------
    Dikkat                          Kya karo
    ------------------------------  --------------------------------
    "claude" command not found      Claude Code install nahi ya
                                    terminal purana hai. Naya kholo.
    "nahi mila" (step 2 check)      Saare windows band karke kholo.
                                    Phir bhi nahi, to step 2 dobara.
    ✘ Failed to connect             1) Token copy me galti? GitHub pe
                                       naya banao, step 2 dobara.
                                    2) Phir bhi ✘: neeche "Plan B".
    Repos list me kuch repos nahi   Token me "Only select
                                    repositories" chuna tha. GitHub
                                    pe token edit karke repo jodo.
    "winget" not found              Microsoft Store se "App Installer"
                                    update karo.
    Galti se token kahin paste/     Turant GitHub > Settings >
    share ho gaya                   Developer settings > Personal
                                    access tokens > token > "Revoke".
                                    Naya banao, step 2 dobara.

    Plan B (sirf jab token sahi ho par ✘ aaye):
        claude mcp remove github --scope user
    phir step 3 wali command me ${GITHUB_PAT} ki jagah asli token daal
    ke chalao. Tab token C:\Users\Anupam Singh\.claude.json file me
    likha rahega. Yeh file repo ke bahar hai, theek hai, bas yeh file
    kabhi kisi ko mat bhejna.


------------------------------------------------------------
11. BAAD ME YAAD RAKHNA
------------------------------------------------------------
    - 90 din baad token expire hoga, github ✘ dikhne lagega. Tab: naya
      token banao (step 1), sirf step 2 dobara karo. Baaki kuch nahi.
    - Claude GitHub pe kuch bhi likhne (PR, issue, push) se pehle
      permission maangta hai. Bina padhe "Yes" mat dabana.
    - git push jo abhi chal raha hai, uspe is setup ka koi asar nahi.
    - Sab hatana ho:
          claude mcp remove github --scope user
          [Environment]::SetEnvironmentVariable('GITHUB_PAT', $null, 'User')
      aur GitHub pe token "Revoke" kar do.
