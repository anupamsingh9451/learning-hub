------------------------------------------------------------
1. EK LINE ME
------------------------------------------------------------
    CodeIgniter (CI) ek halka aur tez PHP framework hai. Seekhna aasan,
    setup chhota, aur kam server pe bhi badhiya chalta hai.

    Misaal: Laravel ek bada SUV hai, sab features andar. CodeIgniter ek
    hatchback hai, halka, sasta, shehar me jaldi pahunchata hai.


------------------------------------------------------------
2. KYUN ZAROORI HAI / KAB USE KAREIN
------------------------------------------------------------
    - Bahut saare client projects aur purane systems CI pe hain.
    - Kam magic, code padhna aur samajhna aasan.
    - Shared hosting pe bhi aaram se chalta hai.

    Kab lo:
    - Chhote-medium business apps, admin panel, simple API.
    - Jahan speed aur kam dependency chahiye.
    Kab Laravel better:
    - Bada SaaS, queues, real-time, bahut saare packages chahiye.


------------------------------------------------------------
3. FOLDER STRUCTURE
------------------------------------------------------------
    app/
        Config/          saari settings (Routes.php, Database.php, Filters.php)
        Controllers/     controllers (BaseController.php yahin)
        Models/          models
        Views/           HTML views
        Filters/         middleware jaisi classes
        Entities/        row ko object banane wali classes
        Database/
            Migrations/  table structure
            Seeds/       starting data
        Helpers/         apne helper functions
        Libraries/       apni libraries
    public/              web root (index.php, css, js, images)
    writable/            logs, cache, session, uploads (likhne ki permission)
    tests/               tests
    vendor/              Composer packages (system/ isi me)
    .env                 settings (git me nahi)
    spark                CLI tool

    Web server ka root hamesha public/ pe rakho. Project ka root public
    karoge toh .env aur code browser se khul sakta hai.


------------------------------------------------------------
4. REQUEST KA SAFAR
------------------------------------------------------------
    STEP 1 – Request public/index.php pe aati hai.
    STEP 2 – Framework load hota hai, .env aur Config padhe jaate hain.
    STEP 3 – Router URL dekh ke controller/method chunta hai.
    STEP 4 – "before" filters chalte hain (login check, CSRF).
    STEP 5 – Controller ka method chalta hai (model se data, view banta).
    STEP 6 – "after" filters chalte hain (headers, toolbar).
    STEP 7 – Response browser ko.

6. ROUTING (app/Config/Routes.php)
------------------------------------------------------------
        $routes->get('/', 'Home::index');
        $routes->get('products', 'Product::index');
        $routes->get('products/(:num)', 'Product::show/$1');
        $routes->post('products', 'Product::create');
        $routes->match(['get', 'post'], 'contact', 'Contact::form');

    Placeholders:
        (:num)       sirf number
        (:alpha)     sirf letters
        (:segment)   slash ke bina kuch bhi
        (:any)       sab kuch, slash bhi

    Naam aur URL banana:
        $routes->get('profile', 'User::profile', ['as' => 'profile']);
        url_to('profile');
        return redirect()->route('profile');

    Group + filter:
        $routes->group('admin', ['filter' => 'auth'], static function ($routes) {
            $routes->get('dashboard', 'Admin\Dashboard::index');
            $routes->resource('users', ['controller' => 'Admin\Users']);
        });

    Auto routing:
    - CI4 me default OFF hai (security ke liye). Har route khud likho.
    - Chahiye toh "Auto Routing (Improved)" on karo, purana legacy wala
      nahi.

    Dekho:  php spark routes

7. CONTROLLER
------------------------------------------------------------
        namespace App\Controllers;

        use App\Models\ProductModel;

        class Product extends BaseController
        {
            public function index()
            {
                $model = new ProductModel();

                return view('products/index', [
                    'products' => $model->where('active', 1)->paginate(10),
                    'pager'    => $model->pager,
                ]);
            }

            public function show(int $id)
            {
                $product = model(ProductModel::class)->find($id);

                if (! $product) {
                    throw \CodeIgniter\Exceptions\PageNotFoundException::forPageNotFound();
                }

                return view('products/show', ['product' => $product]);
            }
        }

    Request se data:
        $this->request->getGet('page');
        $this->request->getPost('email');
        $this->request->getVar('q');          // GET ya POST
        $this->request->getJSON(true);        // JSON body as array
        $this->request->getFile('photo');

    Response:
        return redirect()->to('/products')->with('ok', 'Saved');
        return redirect()->back()->withInput();
        return $this->response->setJSON($data);
        return $this->response->setStatusCode(404);

    BaseController ke initController() me helpers load karo jo har jagah
    chahiye: protected $helpers = ['url', 'form'];

8. VIEWS, LAYOUT, VIEW CELLS

9. MODEL
------------------------------------------------------------
        php spark make:model ProductModel

        class ProductModel extends Model
        {
            protected $table            = 'products';
            protected $primaryKey       = 'id';
            protected $returnType       = 'array';   // ya Entity class
            protected $useSoftDeletes   = true;
            protected $allowedFields    = ['name', 'price', 'active'];
            protected $useTimestamps    = true;

            protected $validationRules  = [
                'name'  => 'required|min_length[3]',
                'price' => 'required|decimal',
            ];
        }

    CRUD:
        $m->findAll();
        $m->find($id);
        $m->where('price >', 100)->orderBy('id', 'DESC')->findAll(10);
        $m->insert($data);               // naya id return
        $m->update($id, $data);
        $m->save($data);                 // id hai toh update, warna insert
        $m->delete($id);                 // soft delete on hai toh soft
        $m->errors();                    // validation errors

    Model events (callbacks):
        protected $beforeInsert = ['hashPassword'];

        protected function hashPassword(array $data): array
        {
            if (isset($data['data']['password'])) {
                $data['data']['password'] = password_hash(
                    $data['data']['password'], PASSWORD_DEFAULT
                );
            }
            return $data;
        }

12. MIGRATION AUR SEEDER

        public function up()
        {
            $this->forge->addField([
                'id'         => ['type' => 'INT', 'unsigned' => true, 'auto_increment' => true],
                'name'       => ['type' => 'VARCHAR', 'constraint' => 150],
                'price'      => ['type' => 'DECIMAL', 'constraint' => '10,2'],
                'active'     => ['type' => 'TINYINT', 'default' => 1],

                'updated_at' => ['type' => 'DATETIME', 'null' => true],
                'deleted_at' => ['type' => 'DATETIME', 'null' => true],

            $this->forge->createTable('products');

        public function down()
        {

        }

14. FILTERS (MIDDLEWARE)
------------------------------------------------------------
        php spark make:filter AuthFilter

        class AuthFilter implements FilterInterface
        {
            public function before(RequestInterface $request, $arguments = null)
            {
                if (! session()->get('user_id')) {
                    return redirect()->to('/login');
                }
            }

            public function after(RequestInterface $request, ResponseInterface $response, $arguments = null)
            {
            }
        }

    Register (app/Config/Filters.php):
        public array $aliases = [
            'auth' => \App\Filters\AuthFilter::class,
            // ... baaki
        ];

    Lagao:
        - Route pe:   ['filter' => 'auth']
        - Sab pe:     $globals['before'] me
        - Method pe:  $methods = ['POST' => ['csrf']]

    CSRF ON karne ke liye Filters.php me globals 'before' me 'csrf' kholo,
    aur form me <?= csrf_field() ?> lagao.

18. REST API
------------------------------------------------------------
        $routes->resource('api/products', ['controller' => 'Api\Products']);

        class Products extends ResourceController
        {
            protected $modelName = ProductModel::class;
            protected $format    = 'json';

            public function index()
            {
                return $this->respond($this->model->findAll());
            }

            public function create()
            {
                $data = $this->request->getJSON(true);
                if (! $this->model->insert($data)) {
                    return $this->failValidationErrors($this->model->errors());
                }
                return $this->respondCreated($data);
            }
        }

    ResponseTrait ke helpers: respond(), respondCreated(), failNotFound(),
    failUnauthorized(), failValidationErrors()

    CORS chahiye toh Config/Cors.php set karo aur 'cors' filter lagao.

19. CI3 vs CI4
------------------------------------------------------------
    Cheez            CI3                      CI4
    -------------    ---------------------    --------------------------
    PHP              5.x/7.x                  8.1+
    Namespace        nahi                     haan (App\Controllers)
    Composer         optional                 zaroori
    Web root         project root             public/
    Model            CI_Model, khali          Model class, CRUD ready
    Middleware       hooks                    Filters
    CLI              nahi                     spark
    Env              config files             .env
    Load             $this->load->model()     new Model() / model()

    Purana CI3 project CI4 pe le jaana = rewrite jaisa hi kaam hai. Sab
    ek saath nahi, module by module karo.

21. GALTIYAN JO MAINE KI / GOTCHAS
------------------------------------------------------------
    - $allowedFields me field nahi daala toh insert/update chupchap use
      chhod deta hai. Error nahi aata, data save nahi hota.
    - baseURL ke end me / lagao, warna links toot sakte hain.
    - Model ki validation fail hui toh insert() false deta hai. Hamesha
      check karo aur $model->errors() dekho.
    - Route me (:any) last me rakho, warna baaki routes kha jaata hai.
    - Controller ka method public hona chahiye.
    - writable/ ki permission na ho toh session aur logs fail hote hain,
      blank page aata hai.

22. INTERVIEW ANGLE
------------------------------------------------------------
    Q: Filters kya hain?
    A: CI4 ka middleware. Controller se pehle (before) ya baad (after)
       chalte hain. Auth, CSRF, CORS ke liye.

    Q: Model ke $allowedFields kyun?
    A: Mass assignment se bachav. Sirf yeh fields form se save hongi.

    Q: Entity kya hai?
    A: Table ki ek row ka object, jisme casts aur getter/setter logic.

    Q: Services kya hain?
    A: Framework ki shared classes (session, email, cache) ek jagah se
       lena. Test me inhe mock kar sakte ho.

    Q: CI4 me CSRF kaise on karte ho?
    A: Config/Filters.php me global 'csrf' filter, form me csrf_field().

    Q: CodeIgniter vs Laravel?
    A: CI halka, tez, kam magic. Laravel me ecosystem bada: queues,
       events, Eloquent relations, starter kits.
