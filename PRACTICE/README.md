# Practice

Chhote code exercises: DSA, katas, snippets.

## File Naming Convention

```
<topic>\<yyyy-mm-dd>-<naam>.<ext>

# Examples:
dsa\2026-10-23-two-sum.py
katas\2026-10-24-fizzbuzz.js
```

## Structure

```
PRACTICE/
├── dsa/          # Data structures & algorithms
├── katas/        # Small coding challenges
├── snippets/     # Reusable code pieces
└── exercises/
    └── week01/   # week-1 ke weekly plan exercises
```

> Week exercises `exercises\week01\...` me rakh sakte ho.
