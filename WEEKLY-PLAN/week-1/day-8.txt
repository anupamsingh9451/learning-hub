0:50 – 1:25  DOMAIN MODELS (asli kaam)
============================================================
Concept pehle samjho:
   Ek INSTITUTION (school/coaching) ke bahut saare USERS hote hain.
   Har user ka ek ROLE: admin, instructor ya student.
   Institution  1 ---- many  User
   (Institution hasMany Users;  User belongsTo Institution)

Step A: Role enum
   app/Enums/Role.php banao – Tuesday wala enum yahan le aao.
   Upar:  namespace App\Enums;

Step B: Institution model + migration + factory
   sail artisan make:model Institution -mf
     (-m = migration, -f = factory)
   Migration me columns:
     - name
     - slug  (unique)               -> $table->string('slug')->unique();
     - contact_email (nullable)     -> ->nullable()
     - is_active (default true)     -> $table->boolean('is_active')->default(true);
     - timestamps                   -> $table->timestamps();

Step C: users table me institution + role
   sail artisan make:migration add_institution_and_role_to_users_table --table=users
   up() me:
     - foreignId('institution_id')->nullable()->constrained()
         (constrained() = foreign key institutions.id se apne aap)
     - string('role')->default('student')
     - index on (institution_id, role)   -> $table->index(['institution_id', 'role']);
   down() me ulta karna mat bhoolna (index drop, foreign key drop, column drop).
     HINT: $table->dropConstrainedForeignId('institution_id');
   Kyun index? "Is institution ke saare students do" – ye query bahut chalegi.

Step D: Relationships + cast
   Institution model:  users()        -> hasMany(User::class)
   User model:         institution()  -> belongsTo(Institution::class)
   User model me role ko enum me cast karo (Laravel 11+ style):
       protected function casts(): array
       {
           return [
               // ... jo pehle se hai
               'role' => Role::class,
           ];
       }
   Ab $user->role ek string nahi, Role::Student jaisa enum milega.

Step E: Factories
   - InstitutionFactory: name, slug (unique), contact_email, is_active
   - UserFactory me 3 "states" – ek line me role set karne ke shortcut:
       admin(), instructor(), student()
     Syntax hint:
       public function admin(): static
       {
           return $this->state(fn (array $attributes) => ['role' => Role::Admin]);
       }
     Use:  User::factory()->admin()->create();
