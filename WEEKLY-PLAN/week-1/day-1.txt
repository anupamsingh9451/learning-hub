STEP 3 – BASELINE TEST (0:30 – 1:30) – 60 min, AI BILKUL NAHI
============================================================
Baseline test kya hai? Ye "pass/fail" wala test nahi hai. Ye ek naap hai ki
AAJ tum kahan ho, taaki 6 mahine baad compare kar sako. Isliye imaandaar raho.

Rules:
    - Har task ke liye 15 minute, timer lagao. Time khatam = ruk jao.
    - Official docs allowed (php.net, laravel.com, react.dev). AI NAHI.
    - Code likhna zaroori hai; chala ke dekh liya to bonus.
    - Har task alag file/folder me likho (e.g. notes\baseline\task1.php)

----- Task 1: PHP (15 min) -----
    interface Shape jisme area(): float method.
    Do classes: Circle aur Rectangle jo Shape implement karein.
    Size 0 ya negative ho to InvalidArgumentException throw karo.
    -> Ye check karta hai: interface, class, constructor, types, exception.

----- Task 2: Laravel (15 min) -----
    POST /api/courses route.
    Validation: title required, max 120 characters; fee integer, min 0.
    Success pe 201 status ke saath bana hua course JSON me return karo.
    -> Ye check karta hai: routes/api.php, controller, $request->validate(),
     model create, response()->json(..., 201).

----- Task 3: SQL (15 min) -----
    Tables: students, courses, enrollments(student_id, course_id, fee_paid).
    Har course ke saath: kitne students aur total fees.
    Sirf wo courses jinme 5 ya zyada students hain. Sabse zyada total pehle.
    -> Ye check karta hai: JOIN, GROUP BY, COUNT, SUM, HAVING (WHERE nahi!),
     ORDER BY ... DESC.
     Yaad rakho: WHERE rows ko group banane se PEHLE filter karta hai,
     HAVING groups ko BAAD me filter karta hai.

----- Task 4: React (15 min) -----
    Email ka form. Submit pe ek fake API call karo (setTimeout 1 second;
    agar email me 'fail' likha ho to error de).
    3 states dikhao: loading, error, success.
    -> Ye check karta hai: useState, form onSubmit, preventDefault, Promise,
     async/await, conditional rendering.
