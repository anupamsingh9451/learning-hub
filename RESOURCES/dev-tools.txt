------------------------------------------------------------
1. YEH FILE KYA HAI
------------------------------------------------------------
    App banate waqt kaam aane wali websites aur tools ki directory,
    category ke hisaab se. "Mujhe icons chahiye / payment lagana hai /
    deploy kahan karun" – seedha us section pe jao.

    Vibe coding = AI (Claude, Cursor, v0) ke saath tezi se app banana.
    Isme sabse zyada time "kaunsa tool lun" me jaata hai. Yeh list wahi
    time bachati hai.

    Kaise padhein:
    - Har section me: Naam, Link, Kis kaam ka.
    - (+) = original Google Doc me nahi tha, maine joda (Laravel, Indian
      payments, Claude, dev utilities ke liye).
    - Section ke neeche "Tip" = kab kya chunna hai.
    - Saare links 24-10-2026 ko check kiye. Original doc ke 5 links ka
      address badal gaya tha (Origin UI, Lenis, Neon, Railway, Godly),
      yahan naye address hain. Backlit UI band ho gaya, isliye hata diya.
