2. PROMPT: COMPONENT LIBRARIES SETUP (SHADCN / DAISYUI / FLOWBITE)
------------------------------------------------------------
    Repos: shadcn-ui/ui, saadeghi/daisyui, themesberg/flowbite, radix-ui

    [PROMPT START]
    Act as a Senior Design Systems Architect.
    Set up the foundational UI component system for my web project.

    Project Type: [React / Next.js OR Laravel Blade / PHP]

    Requirements:
    1. If React/Next.js: Configure base Tailwind + shadcn/ui with Radix
       primitives and Lucide icons. Provide drop-in code for: Button,
       Dialog/Modal, DropdownMenu, and Card.
    2. If Laravel/Blade: Configure Tailwind + daisyUI (ya Flowbite).
       Provide clean reusable Blade components (`<x-button>`, `<x-modal>`,
       `<x-card>`) with no heavy JS build dependencies.
    3. Ensure clean dark/light mode token structure, focus-visible
       accessibility rings, and consistent 8px spacing rhythm.
    [PROMPT END]

3. PROMPT: MODERN SAAS LANDING PAGE (MAGIC UI / SKIPER STYLE)
------------------------------------------------------------
    Repos: magicuidesign/magicui, skiper-ui, motiondivision/motion, lucide

    [PROMPT START]
    Act as a Lead Frontend Engineer and Creative UI Designer.
    Create a high-converting, modern SaaS landing page.

    Structure Required:
    1. Floating Header: Glassmorphism blurred pill navbar with brand logo,
       links (Features, Platform, Pricing), and a high-contrast CTA button.
    2. Hero Section:
       - Subtle background radial glow gradient.
       - Animated announcement pill ("v2.0 Launched").
       - Bold headline with subtle gradient text highlight.
       - Dual CTAs: Primary solid button with glow + Secondary demo button.
       - Social proof: Customer avatar stack + 5-star rating text.
    3. Bento Grid Features (Magic UI style):
       - 1 wide 2-column card showcasing code/terminal preview.
       - 3 modular feature cards with Lucide icons and hover lift effect.
    4. Interactive Pricing:
       - Monthly / Annual billing toggle.
       - 2 to 3 tiers with a prominent "Recommended" badge on Pro.
    5. Testimonials & CTA Banner:
       - Quote cards with author photo, role, and company.
       - Final bottom call-to-action banner.

    Design Style: Slate-950 dark theme, Plus Jakarta Sans font, crisp
    1px slate-800 borders, smooth transitions.
    [PROMPT END]

5. PROMPT: INTERACTIVE DATA TABLE & FILTERS (TANSTACK STYLE)
------------------------------------------------------------
    Repos: TanStack/table, ant-design/ant-design, tabler-icons

    [PROMPT START]
    Build a production-ready, interactive Data Table page with advanced
    search, multi-status filters, sorting, and pagination.

    Requirements:
    1. Controls Bar:
       - Instant live search input (filters across name and email columns).
       - Status tab pills: "All", "Paid", "Pending", "Failed" with counts.
       - Export CSV button and "Add New" trigger.
       - Bulk selection actions (visible when rows are checked).
    2. Table Header:
       - Checkbox for select all.
       - Sortable column headers (Name, Status, Date, Plan, Amount).
    3. Table Rows:
       - Customer avatar + name + email in first cell.
       - Color-coded status badge (Green = Paid, Yellow = Pending, Red = Failed).
       - Date and formatted currency amount.
       - Action dropdown button (View, Edit, Delete).
    4. Pagination:
       - "Showing X to Y of Z entries".
       - Previous / Next buttons with page number buttons.
    [PROMPT END]

7. PROMPT: LARAVEL BLADE FULL PAGE (DAISYUI / FLOWBITE)
------------------------------------------------------------
    Repos: saadeghi/daisyui, themesberg/flowbite, chartjs/Chart.js

    [PROMPT START]
    Create a clean Laravel Blade template for a [Page Name, e.g. User Profile /
    Order Details / Management Screen] using daisyUI and Tailwind CSS.

    Rules:
    - Pure HTML + Blade syntax + daisyUI classes. No React or Vue needed.
    - Use `@extends('layouts.app')` or standalone HTML with CDN scripts.
    - Implement accessible daisyUI components: `card`, `btn`, `badge`,
      `table`, and `modal`.
    - Include Blade directive placeholders (`@foreach`, `@if`, `{{ $var }}`)
      and CSRF token (`@csrf`) in all forms.
    - Include mobile-responsive navbar and drawer.
    [PROMPT END]
