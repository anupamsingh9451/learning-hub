Act as a Senior UI Engineer.
Design a modern, responsive Navigation Bar and Header system based on Navbar Gallery best practices.

Requirements:
1. Desktop Floating Nav:
   - Floating glassmorphism pill layout (`backdrop-blur-md`, subtle 1px border `rgba(255,255,255,0.08)`, soft shadow).
   - Brand logo with hover micro-rotation.
   - Categorized links (Features, Solutions, Docs, Pricing).
   - Solutions Mega-Menu: Multi-column dropdown showcasing categorized product links with Lucide icons, short descriptions, and a highlighted "What's New" card.
   - Action triggers: Quick search shortcut pill (Cmd+K), Theme toggle, and solid Primary Action button.
2. Mobile Slide-Over Drawer:
   - Smooth slide-over drawer triggered by animated hamburger icon.
   - Accordion collapse for sub-menus.
   - Bottom user authentication and action buttons.
3. Scroll Dynamic Behavior:
   - Shrink slightly on scroll down; elevate subtle backdrop on reverse scroll up.
