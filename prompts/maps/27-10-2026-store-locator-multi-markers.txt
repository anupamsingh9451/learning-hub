Act as a Senior Frontend Engineer.
Build a production-grade, interactive Store Locator component with multiple markers and search filtering.

Project Context:
- Tech Stack: [React / Next.js / Tailwind CSS OR Blade / Plain JS]
- Locations Data: [Array of 5-10 locations with Name, Address, Phone, Lat, Lng, Status]

Layout & Features:
1. Split-View Layout:
   - Left Sidebar (1/3 width on desktop):
     * Search bar to filter stores by city or name.
     * Scrollable list of store cards showing name, distance/city, hours, and "View on Map" button.
     * Active state indicator on the currently selected store card.
   - Right Map Area (2/3 width on desktop):
     * Interactive map rendered with MapLibre GL JS (or Leaflet).
     * Branded SVG pin marker for every store in the dataset.
2. Interactive Synchronization:
   - Clicking a store in the left list smoothly fly-to/pans the map to that coordinate, zooms in, and opens its interactive popup.
   - Clicking a marker on the map highlights and scrolls to that store's card in the left list.
3. Marker Clustering & Camera Bounds:
   - Enable marker clustering when multiple stores are close to each other.
   - Automatically fit map camera bounds (`fitBounds()`) on initial load so all markers are visible with comfortable padding.
4. Styling:
   - Dark/Modern slate UI container (`bg-slate-900 border border-slate-800 rounded-2xl overflow-hidden shadow-xl`).
