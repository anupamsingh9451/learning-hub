Act as an Email Systems Engineer.
Implement a reliable Transactional Email pipeline using Resend and React Email (or Laravel Mailables).

Project Context:
- Tech Stack: [Next.js / Node.js OR Laravel PHP]
- Email Provider: [Resend OR Postmark]
- Sender Address: [e.g. notifications@yourdomain.com]

Requirements:
1. Architecture & Client Setup:
   - Initialize the Resend SDK with API Key from environment variables.
   - Set up background queue or asynchronous execution so email dispatch never blocks user HTTP requests.
2. Responsive Email Templates (React Email / HTML):
   - Welcome Email: Personal greeting, getting started checklist, and "Launch App" CTA button.
   - Magic Link / OTP Code: Clean security email with expiring verification code or 1-click login link.
   - Payment Receipt / Invoice: Itemized billing breakdown, transaction ID, and PDF download button.
   - Team Invite Email: Organization name, inviter avatar, and "Accept Invitation" button.
3. Fallbacks & Deliverability:
   - Plain text fallback generation for every email.
   - Domain verification headers: SPF, DKIM, DMARC guidelines.
   - Error handling: Catch delivery exceptions and log error details without crashing user flows.
