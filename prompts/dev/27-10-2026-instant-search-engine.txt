Act as a Search Infrastructure & Database Engineer.
Implement a lightning-fast, typo-tolerant Instant Search engine using Meilisearch (or Typesense / Algolia).

Project Context:
- Tech Stack: [Next.js 15 App Router OR Laravel 11 with Laravel Scout]
- Search Engine: [Meilisearch (self-hosted / cloud) OR Algolia OR Typesense]
- Search Dataset: [Products / Articles / Users / Documentation]

Requirements:
1. Index Configuration & Search Settings:
   - Searchable attributes (Title, Description, Tags, Category).
   - Filterable attributes (Price, InStock, Brand, Category, Rating).
   - Sortable attributes (Price asc/desc, Date, Popularity).
   - Custom ranking rules: Exact word matches ranked higher than partial matches.
   - Typo-tolerance enabled (handling 1-2 character typos seamlessly).
2. Database Synchronization Pipeline:
   - On DB record Create / Update / Delete, automatically sync the document to the search index (via database triggers, ORM hooks, or background job queue).
3. Instant Search UI:
   - Modern search modal / dropdown with search-as-you-type (< 50ms latency).
   - Faceted filter sidebar: Category checkboxes, price range slider, and sort dropdown.
   - Highlight matched terms inside result titles and snippets.
   - Zero results fallback: "Did you mean [suggested term]?" and recommended items.
