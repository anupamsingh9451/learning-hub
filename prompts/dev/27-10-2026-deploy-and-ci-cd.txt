Prepare and configure my application for zero-downtime production deployment on Vercel or Railway.

- Database: [Neon Postgres / Supabase / Railway Postgres]

Requirements:

   - Add a `/api/health` route that verifies: Database connectivity, Redis ping, and returns `{ status: "ok", timestamp: ... }`.
4. Build & Deployment Pipeline:
   - GitHub Actions workflow (`.github/workflows/deploy.yml`) for automated linting, test execution, and deployment on merge to `main`.
5. Post-Deployment Verification Steps:
   - Verification checklist for custom domain, SSL certificate, DNS records (A/CNAME), and error logging verification.
